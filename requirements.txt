# Full dependency set for LOCAL training/ingestion. The live API deployed via
# pyproject.toml only needs the lean subset — see requirements-api.txt.

# Versions are PINNED, not >=, on purpose. An earlier install with only >=
# constraints silently pulled pandas 3.0.2 (a major version with real breaking
# changes from 2.x) and lightgbm 4.7.0 (which deprecated the eval_set= API used
# in models/*.py). Both were caught by actually running the pipeline, not by
# reading the code. Pinning exact tested versions here prevents that surprise
# from recurring silently. If you deliberately want to move to newer versions,
# do it as a conscious upgrade — re-run the full pipeline and check for new
# deprecation warnings, don't let pip pick a newer version for you by accident.
#
# entsoe-py 0.8.0 is the version that actually performed the 52,522-row pull on
# this machine (0.6.19 was only ever declared). Both score 0 OSV advisories, so
# this is a reproducibility correction, not a security one.
entsoe-py==0.8.0
pandas==3.0.2
numpy==2.4.4
# 2.32.3 had 2 distinct CVEs (CVE-2024-47081, CVE-2026-25645) across 4 advisories
# in OSV; 2.34.2 has 0. This is the library that authenticates to NASA POWER.
